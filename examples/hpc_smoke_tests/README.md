# HPC smoke tests for the fine-tuning workflow

Four small jobs that check each piece of the workflow on your cluster before a
real campaign. Generated by `make_smoke_tests.py` in the samson-mlip-visualizer
repository (`examples/hpc_smoke_tests/`). Nothing here has been submitted.

| Folder | What it checks | Resources | Time |
|---|---|---|---|
| `01_label_gaussian` | Gaussian `Force` jobs, and that the collector reads real logs | 3 × 8 cores, CPU | minutes |
| `02_label_orca` | the same for ORCA `EnGrad` | 3 × 8 cores, CPU | minutes |
| `03_train_plain` | mace-torch fine-tuning on a GPU node: 87 HCN/HNC structures, 1 seed, 5 epochs | 1 GPU | ~1 min of training |
| `04_train_multihead_mp` | multihead fine-tuning with 500 Materials Project replay structures, 1 seed, 3 epochs | 1 GPU | a few min |

## Steps

1. Copy this folder to the cluster.
2. Fill in the placeholders in each `*.slurm` script: `<ACCOUNT>`, the
   partitions, the `module load` lines, and for 03/04 the line that activates
   a Python environment with `mace-torch==0.3.16` (each folder's README lists
   what is left).
3. For 04, on a **login node**: `bash download_mp_replay.sh` (≈595 MB into
   `~/.cache/mace`; compute nodes often have no internet).
4. In each folder: `sbatch run_gaussian.slurm`, `sbatch run_orca.slurm`,
   `sbatch run_train.slurm` (twice, in 03 and 04). You can skip any code you
   do not use.
5. Copy back `outputs/` (01, 02) and `runs/` (03, 04) into the same folders
   on your desktop, plus `logs/` if a job failed.
6. On the desktop, in SAMSON's Python, from this folder:
   `python check_smoke_results.py`. It prints PASS / FAIL / NOT RUN per test:
   - 01/02: every output accepted, and the barrier, reaction energy, and
     forces within 0.02 eV and 0.05 eV/Å of Psi4 PBE/def2-TZVP on the same
     geometries (`reference_psi4_pbe_def2tzvp.json`);
   - 03/04: the model loads, keeps all foundation elements, evaluates HCN
     and water, and (04) has both heads.

The three geometries are HCN, the transition state, and HNC from the
MACE-MP-0 IRC (C, N, H order). With PBE, the barrier on these geometries
should come out near 2.0 eV.
